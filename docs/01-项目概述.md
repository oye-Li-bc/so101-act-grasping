# 01 项目概述

## 1. 项目目标

在 SO-ARM101 六自由度机械臂上，通过**模仿学习（Imitation Learning）**实现"抓取纸巾团并放置到目标位置"的完整任务闭环：示教数据采集 → 模型训练 → 真机部署 → 迭代优化。

## 2. 技术路线

```
主臂示教（人类操作） → 从臂跟随录制 → LeRobot 数据集
    → ACT 模型训练（模仿学习） → 真机部署 → 抓取-放置 ✅
```

- **框架**：LeRobot 0.6.1
- **策略**：ACT (Action Chunking Transformer)，52M 参数
- **平台**：SO-ARM101（主臂示教 + 从臂执行）
- **感知**：单目 RGB 相机（1080p, 25 FPS）

## 3. 核心成果

| 指标 | 数值 |
|------|------|
| 数据集 | 40 条示教轨迹，10,000 帧（25 FPS, 1080p） |
| 模型 | ACT，52M 参数，8000 步训练 |
| L1 Loss（动作偏差） | **0.257** |
| KL Loss（VAE 稳定性） | **0.015** |
| 真机表现 | **稳定抓取纸巾团并放置到位** ✅ |

## 4. 关键工程发现

1. **部署分辨率必须与训练一致**（1920×1080），否则模型误判距离，机械臂停在目标上方 5cm。
2. **1080p 下相机必须使用 MJPG 编码**，否则回退 YUYV 仅 5 FPS。
3. **n_action_steps=50（2 秒/块）优于 25**：衔接平滑度收益 > 矫正频率收益。
4. **数据不平衡陷阱**：夹爪张合帧占比过低时，即使 L1 Loss 很小，模型也学不会夹取。
