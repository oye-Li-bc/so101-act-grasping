# 04 部署与迭代

## 1. 部署命令

```bash
PYTHONPATH="" lerobot-rollout \
    --policy.type=act \
    --policy.pretrained_path=./oye_tissue_full/checkpoints/008000/pretrained_model \
    --policy.input_features="{ observation.state: {type: STATE, shape: [6]}, observation.images.front: {type: VISUAL, shape: [3, 1080, 1920]} }" \
    --policy.output_features="{ action: {type: ACTION, shape: [6]} }" \
    --policy.n_action_steps=50 \
    --robot.type=so101_follower \
    --robot.id=oye_follower_arm \
    --robot.port=/dev/ttyACM0 \
    --robot.cameras="{ front: {type: opencv, index_or_path: /dev/video2, width: 1920, height: 1080, fps: 25, fourcc: \"MJPG\"}}" \
    --display_data=true
```

**⚠️ 部署时必须显式指定 input/output features**：rollout 无法像训练那样从数据集自动推断特征。

## 2. 部署中踩过的坑（按排查顺序）

### 2.1 特征校验失败

```
ValueError: You must provide at least one image or the environment state among the inputs.
```

**原因**：LeRobot 0.6.1 中 `FeatureType` 比较用的是 `is`，而 JSON 反序列化后是字符串，比较失败。

**解决**：修复 `policies.py` 中 4 处 `is` → `==`。

### 2.2 相机 FPS 校验失败

```
RuntimeError: OpenCVCamera(/dev/video2) failed to set fps=30 (actual_fps=25.0)
```

**原因**：摄像头实际只支持 25 FPS。

**解决**：`fps=25`，与数据采集一致。

### 2.3 机械臂"停在目标上方 5cm"（关键问题）

**现象**：模型能准确靠近目标，但停在目标上方约 5cm，不继续下降抓取。

**排查过程**（三层排查法：数据 → 模型 → 部署）：

| 层 | 检查 | 结论 |
|------|------|------|
| 数据 | 夹爪张合幅度 62.3° | ✅ 数据没问题 |
| 模型 | L1=0.257，KL=0.015 | ✅ 模型没问题 |
| 部署 | 相机分辨率 **640×480** vs 训练 **1920×1080** | ❌ **不匹配！** |

**根因**：部署时相机分辨率与训练数据不一致。模型在 1080p 大图里学到的"物体大小 ↔ 距离"映射关系，在 640×480 小图下失效——物体显得更大，模型误判距离，提前停手。

**解决**：部署分辨率改为 1920×1080，与训练一致。

### 2.4 1080p 下 FPS 又失败

```
failed to set fps=25 (actual_fps=5.0)
```

**原因**：1080p 下未指定 `fourcc`，相机回退到 YUYV 原始格式，带宽不足只有 5 FPS。

**解决**：指定 `fourcc: MJPG` 压缩格式（与录制时一致）。

## 3. 成功部署

分辨率对齐 + MJPG 后，模型**稳定抓取纸巾团并放置到目标位置**。

## 4. 部署参数 vs 训练参数对照表

| 参数 | 训练 | 部署 | 必须一致？ |
|------|------|------|------|
| 分辨率 | 1920×1080 | 1920×1080 | ✅ 是（否则误判距离） |
| FPS | 25 | 25 | ✅ 是 |
| fourcc | MJPG | MJPG | ✅ 是 |
| n_action_steps | 50 | 50 | ✅ 是（维度匹配） |
| 关节数 | 6 | 6 | ✅ 是 |
