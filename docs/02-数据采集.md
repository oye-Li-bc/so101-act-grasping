# 02 数据采集

## 1. 任务定义

**抓取-放置（Pick-and-Place）**：从臂将目标物体（橙色胶带包裹的纸巾团）从初始位置抓起，放置到指定目标位置。

选择纸巾团作为目标物体，而非更小的糖果，原因：

| 物体 | 夹取难度 | 原因 |
|------|------|------|
| 糖果 | 高 | 体积小、表面光滑、夹爪容易打滑 |
| 纸巾团 | 低 | 体积大、有弹性形变、摩擦力好 |

## 2. 采集方案

采用**主臂示教（Teleoperation）**方式：人类操作主臂，从臂实时跟随，全程录像并记录关节角度。

### 关键参数

| 参数 | 值 | 说明 |
|------|------|------|
| 数据集 | `oye-Li-bc/oye_tissue` | 命名规范：`oye` 标识 + 物体 + 时间戳 |
| 条数 | 40 episodes | 比首次采集（14 条）多近 3 倍 |
| 单条时长 | 20 秒 | 25 FPS × 20s = 500 帧/条 |
| 复位时间 | 5 秒 | 条与条之间手动摆放物体 |
| 总帧数 | 10,000 帧 | 40 × 500 |

### 硬件配置

```
主臂：/dev/ttyACM1，oye_leader_arm（示教）
从臂：/dev/ttyACM0，oye_follower_arm（跟随）
相机：/dev/video2，1920×1080，25 FPS，MJPG 编码
```

## 3. 采集要点（踩坑总结）

### 3.1 夹爪动作必须"明显"

模仿学习的模型是从数据里学动作的。如果夹爪在整个轨迹里变化很小，模型就"学不到"夹取动作。因此录制时要求：

- 每条轨迹中夹爪**张开幅度要大**（0° → 60°+）
- 张合动作**清晰可分**（张开 → 夹紧 → 保持）
- 避免长时间保持夹紧不动

### 3.2 位置变体

- 物体放在**不同位置**（左/中/右、近/远）
- 相同位置不超过 2 条
- 覆盖任务可能遇到的空间分布

### 3.3 数据质量检查

录制完成后，用 `scripts/analyze_dataset.py` 检查：

```bash
python scripts/analyze_dataset.py oye-Li-bc/oye_tissue_20260815_133841
```

**必须检查的指标**：

| 指标 | 阈值 | 本次实际 |
|------|------|------|
| 夹爪变化幅度 | > 30° | 62.3° ✅ |
| 夹爪张开帧占比 | > 15%（否则模型学不会夹取） | 30.6% ✅ |
| 各关节动作范围 | 无明显死区 | ✅ |

## 4. 命名规范

| 项 | 命名 | 说明 |
|------|------|------|
| 数据集 repo | `oye-Li-bc/oye_tissue` | 与糖果数据集 `oye` 区分 |
| 校准文件 | `oye_leader_arm` / `oye_follower_arm` | 机械臂固定，校准文件不变 |
| 模型输出 | `oye_tissue_full` | 训练输出目录 |
